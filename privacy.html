Política de Privacidade

Última atualização: Maio de 2025

1. Informações que coletamos

O Assistente de Pré-Vendas G4 coleta as seguintes informações durante o uso:

  • Segmentos de mercado pesquisados: Os termos de busca inseridos pelos usuários (ex: "Construtoras", "Clínicas") são enviados ao nosso servidor para gerar o briefing de inteligência de mercado.
  • Código de acesso: Armazenado localmente no navegador do usuário para manter a sessão ativa.
  • Histórico de pesquisas: Armazenado localmente no navegador para facilitar buscas repetidas.

2. Como usamos essas informações

As informações coletadas são usadas exclusivamente para:

  • Gerar briefings de inteligência de mercado através da API da Anthropic
  • Autenticar usuários autorizados via código de acesso
  • Melhorar a experiência do usuário através do histórico de buscas

3. Compartilhamento de dados

Os segmentos pesquisados são processados pela Anthropic (fornecedora da API de inteligência artificial) para gerar os briefings. A Anthropic possui sua própria política de privacidade disponível em anthropic.com/legal/privacy.

Não compartilhamos, vendemos ou transferimos dados dos usuários para terceiros além do necessário para o funcionamento da ferramenta.

4. Armazenamento de dados

O código de acesso e o histórico de pesquisas são armazenados apenas no navegador do usuário (sessionStorage), não em nossos servidores. Esses dados são apagados ao fechar a aba ou navegador.

5. Segurança

Todas as comunicações entre a extensão e nosso servidor são feitas através de conexão segura (HTTPS). A chave da API da Anthropic é armazenada de forma segura no servidor, nunca exposta aos usuários.

6. Seus direitos

Você pode a qualquer momento:

  • Limpar o histórico de pesquisas ao fechar o navegador
  • Desinstalar a extensão, removendo todos os dados locais
  • Solicitar esclarecimentos sobre o uso de seus dados

7. Contato

Para questões sobre privacidade, entre em contato através do seu coordenador de pré-vendas da G4 Educação.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data de última atualização será sempre indicada no topo desta página.
